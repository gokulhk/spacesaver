# Test fixtures

Synthetic media for `:core:media` instrumented tests, generated by [`generate.sh`](generate.sh) with ffmpeg and committed to `core/media/src/androidTest/assets/`. Everything is generated from ffmpeg's built-in test sources, so it is free of copyright (CC0).

| File | What | Used for |
|---|---|---|
| `video_4k_h264.mp4` | 2 s, 3840×2160, 30 fps, H.264 20 Mbps, AAC 128 kbps, creation time `2024-06-11T18:15:02Z`, location `+37.4220-122.0841` | 4K → 1080p conversion, metadata preservation |
| `video_1080p_h264.mp4` | 2 s, 1920×1080, H.264 8 Mbps, AAC | Full HD → HD conversion |
| `photo.jpg` | 1600×1200 smooth gradients | JPEG → HEIC / WebP |
| `photo.png` | 800×600 smooth gradients | photo-like PNG → lossy WebP |
| `screenshot.png` | 1080×2400 flat UI blocks with an embedded picture | screenshot PNG → lossless WebP |

Phone-shaped video variants (about 0.4 MB each, generated by [`generate-video-variants.sh`](generate-video-variants.sh), separate so the originals above stay byte-for-byte unchanged):

| File | What | Used for |
|---|---|---|
| `video_portrait_rot90_stereo.mp4`, `video_portrait_rot270_stereo.mp4` | 1920×1080 frames with a 90° / 270° rotation in the container, stereo AAC | portrait stays portrait (how phones store portrait video) |
| `video_portrait_native_stereo.mp4` | 1080×1920 frames, no rotation flag | portrait stays portrait |
| `video_51_aac.mp4`, `video_ac3.mp4`, `video_opus.mp4` | 5.1 AAC, AC-3 and Opus soundtracks | channels kept; unsupported audio fails with its name |
| `video_hevc_stereo.mp4` | HEVC with stereo AAC | what recent phones record |
| `video_two_audio_tracks.mp4` | stereo plus a second mono audio track | multi-track videos are refused, not silently trimmed |
| `video_no_audio.mp4` | no audio track | a silent video converts and stays silent |

ffmpeg can't write EXIF, so tests stamp EXIF (date taken, GPS, orientation, make and model) onto a copy of `photo.jpg` with `ExifInterface` before converting. The expected values live in the tests.

## Regenerating

```
brew install ffmpeg        # or your platform's package
fixtures/generate.sh                  # the original fixtures
fixtures/generate-video-variants.sh   # the phone-shaped video variants
```

Keep fixtures small; they are part of the repository.
