# Test fixtures

Synthetic media for `:core:media` instrumented tests, generated by [`generate.sh`](generate.sh) with ffmpeg and committed to `core/media/src/androidTest/assets/`. Everything is generated from ffmpeg's built-in test sources, so it is free of copyright (CC0).

| File | What | Used for |
|---|---|---|
| `video_4k_h264.mp4` | 2 s, 3840×2160, 30 fps, H.264 20 Mbps, AAC 128 kbps, creation time `2024-06-11T18:15:02Z`, location `+37.4220-122.0841` | 4K → 1080p conversion, metadata preservation |
| `video_1080p_h264.mp4` | 2 s, 1920×1080, H.264 8 Mbps, AAC | Full HD → HD conversion |
| `photo.jpg` | 1600×1200 smooth gradients | JPEG → HEIC / WebP |
| `photo.png` | 800×600 smooth gradients | photo-like PNG → lossy WebP |
| `screenshot.png` | 1080×2400 flat UI blocks with an embedded picture | screenshot PNG → lossless WebP |

ffmpeg can't write EXIF, so tests stamp EXIF (date taken, GPS, orientation, make and model) onto a copy of `photo.jpg` with `ExifInterface` before converting. The expected values live in the tests.

## Regenerating

```
brew install ffmpeg        # or your platform's package
fixtures/generate.sh
```

Keep fixtures small; they are part of the repository.
