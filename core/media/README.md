# `:core:media`

Media engine: `MediaConverter` strategies (Media3 Transformer for video; WebP and HEIC for images), the `ConverterRegistry`, encoder capability detection, metadata preservation, output writing and verification.

- **May depend on:** `:core:domain`, `:core:model`, Media3, HeifWriter, ExifInterface.
- **Must not depend on:** UI code, `:core:data`.
- **Status:** Arrives in Phase 4.
