# ADR-0001: Minimum SDK is Android 11 (API 30)

- **Status:** Accepted
- **Date:** 2026-10-04

## Context

SpaceSaver deletes originals in batches after the user reviews conversions. On Android 10 and earlier, deleting media the app did not create requires either a separate `RecoverableSecurityException` prompt per file or broad storage access. Scoped storage behaves differently across Android 10 and 11, which multiplies code paths and test effort.

## Decision

Set `minSdk = 30`. This gives us:

- `MediaStore.createDeleteRequest`, which shows **one** system confirmation for many files.
- Stable scoped-storage behavior, so we never need `MANAGE_EXTERNAL_STORAGE`.
- `IS_PENDING` and relative paths for writing outputs next to originals.

`compileSdk` and `targetSdk` track the latest stable API level (pinned in `gradle/libs.versions.toml`).

## Consequences

- Devices on Android 10 and earlier cannot install the app.
- One deletion code path and simpler tests.
- Instrumented tests run on API 30 (minimum) and the latest API level in CI.
